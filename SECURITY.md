# Security

Do not place credentials or private examples in public issues. For a suspected
security issue, use GitHub's private vulnerability reporting if enabled, or
contact the repository owner privately through their published contact method.

ContractLens does not fetch reference URLs, execute specification content or
send telemetry. HTML strings from specifications are escaped. Input files are
not validated against the complete OpenAPI meta-schema. Apply normal resource
limits when processing untrusted or very large documents.
